# StudyFlow AI

A beginner-friendly study planning web application built with Python and Streamlit.

## About the Project

StudyFlow AI is designed to help students organize assignments, track deadlines, and manage their study workload.

The long-term goal is to integrate open-source artificial intelligence to generate personalized study schedules.

## Current Features

- Add assignments and subjects
- Estimate study hours
- Select assignment deadlines
- Track multiple assignments during a session
- Automatically sort assignments by deadline
- Display days remaining until deadlines
- Identify overdue assignments

## Technologies Used

- **Python** — Application programming
- **Streamlit** — Web application interface
- **Git & GitHub** — Version control

## Installation

Clone the repository:

```bash
git clone https://github.com/BrandonAllah/StudyFlowAI.git
cd StudyFlowAI
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```
